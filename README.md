# TelezhkaProxy bot

Бот продаёт подписки и сам заводит клиентов в панели 3X-UI v3.x (новый API `/panel/api/clients/*`, вход по Bearer-токену). Один юзер = один ключ на страну. Можно подключить сколько угодно локаций, сейчас настроена одна, Польша.

## Запуск

```bash
cp .env.example .env      # заполнить
py -3.12 -m pip install -r requirements.txt
py -3.12 bot.py
# или на сервере: docker compose up -d --build
```

После запуска напиши боту `/locs`. Если выдало ✅ с портом и протоколом, значит API панели доступен.

## Тарифы

Тарифы лежат в `app/config.py` → `PLANS`. Тариф «Все страны» сам появится, когда в `.env` будет хотя бы 2 локации.
Новая страна: раскомментировать блок `LOC_DE_*` (или другой) в `.env` и перезапустить бота.

## Важно

- **API-токен.** Панель → Настройки → Безопасность → API Token, scope **admin** (с monitor или node-sync бот получит 403). Логин и пароль боту не нужны.
- **Какие inbound'ы выдавать** задаёт `LOC_PL_INBOUND_ID`: одно число или список, например `1,2,3`. Клиент в панели один (общий трафик и срок), просто прикреплён ко всем трём. Поменял список, и при следующем продлении клиент сам переедет.
- **Лимит устройств** (`DEVICE_LIMIT`) в 3X-UI работает, только если на сервере включён IP Limit (fail2ban). Без него поле просто игнорируется.
- **Торренты на безлимите.** Закрой их в панели: Xray Configs → Routing, правило `protocol: bittorrent` → `blocked`.
- **Подписка через панель** (`LOC_PL_SUB_URL`): бот выдаёт юзеру ссылку встроенного сервера подписок 3X-UI. Это основной вариант.
- **Склейка подписок** (`SUB_PUBLIC_URL`): одна ссылка сразу на все страны. Сервер склейки ходит в подписки панелей и объединяет их. Запускается внутри бота (`WEB_PORT`) или отдельно: `python sub_server.py` на любом сервере с доменом (нужны только `SUB_SOURCES`, база бота не нужна). С ним юзер получает одну ссылку на все страны, а приложение показывает трафик и срок. Вешай за Caddy с доменом.
- `.env` и `data/` в гите не хранятся. Репу держи приватной.
